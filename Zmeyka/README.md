# Проект «Змейка» (Zmeyka) — iOS 6.1.3 (iPhone 4S)

Полноценная нативная классическая игра «Змейка», разработанная в строгой эстетике и системных стандартах iOS 6 для смартфона **iPhone 4S (iPhone4,1)**.

---

## 1. Спецификация и совместимость

- **Целевое устройство:** Apple iPhone 4S (iPhone4,1).
- **Архитектура:** `armv7` (32-bit Mach-O ARM).
- **Минимальная версия iOS:** iOS 6.0 (`Deployment Target = 6.0`).
- **Проверенная совместимость:** iOS 6.1.3.
- **Дисплей:** 3.5" Retina display (физическое: 960 × 640 px, логическое: 320 × 480 pt).
- **Ориентация:** Portrait (книжная).
- **Язык интерфейса:** Русский.
- **Автономность:** 100% офлайн (без сетевых запросов).
- **Стек технологий:** Objective-C, UIKit, CoreGraphics, QuartzCore, AudioToolbox, Foundation. Никаких сторонних тяжелых фреймворков, никакого WebView или Swift/SpriteKit.

## 3. Игровая логика и дизайн

### Игровой процесс
- **Сетка:** 15 × 15 клеток. Размер клетки адаптирован под разрешение iPhone 4S с учётом системной полосы счета и нижнего блока кнопок.
- **Змейка:** Стартует по центру поля (длина 3 сегмента), движется вправо. При движении отрисовываются округлые сегменты с чешуйками и голова с выразительными глазами и бликами.
- **Еда:** Спелое яблоко с листочком и естественной тенью. Генерируется **строго в свободных клетках**, исключая тело змейки.
- **Коллизии:** Честное определение столкновения со стенками и собственным телом. Разворот на 180° аппаратно блокируется.
- **Скорость:** Каждое съеденное яблоко сокращает интервал тика таймера от 0.22 сек до 0.08 сек.
- **Управление (Dual Control):**
  1. Экранные глянцевые кнопки D-Pad (▲, ▼, ◀, ▶) со звуковым кликом.
  2. Сенсорные свайпы (`UISwipeGestureRecognizer` во всех 4 направлениях).
- **Сохранение рекорда:** Автоматически через `NSUserDefaults` с мгновенной синхронизацией.
- **Экраны:**
  - **Главное меню:** Логотип «Змейка», декоративная плашка, отображение рекорда, кнопка управления звуком, кнопка «ИГРАТЬ».
  - **Игровой экран:** Верхний бар (Счёт, Рекорд, кнопка Паузы), поле, D-Pad контроллер.
  - **Пауза:** Модальная карточка с заморозкой таймера и кнопками «Продолжить», «Заново», «В меню».
  - **Game Over:** Индикатор «Игра окончена», итоговые очки, плашка «Новый рекорд!», кнопки «Ещё раз» и «В меню».

## 4. Сборка и компиляция под ARMv7

Так как разработка велась на компьютере под управлением Windows 11, а для компиляции 32-битного бинарного файла iOS 6 под архитектуру ARMv7 требуется специализированный toolchain (`cctools-port` + `ld64` + `iPhoneOS6.1.sdk`), в проекте настроен полностью автоматизированный пайплайн в GitHub Actions:

### Конфигурация CI/CD (`.github/workflows/build.yml`)
Workflow запускается на Ubuntu runner и выполняет:
1. Клонирование и сборку `apple-libtapi` и `cctools-port` с таргетом `arm-apple-darwin11`.
2. Установку утилиты подписи `ldid`.
3. Подключение официального `iPhoneOS6.1.sdk`.
4. Компиляцию исходных кодов с помощью `clang -target arm-apple-darwin11 -arch armv7 -miphoneos-version-min=6.0 -fobjc-arc`.
5. Линковку нативного Mach-O бинарника `arm-apple-darwin11-ld` с фреймворками UIKit, Foundation, CoreGraphics, QuartzCore, AudioToolbox.
6. Псевдоподпись бинарника через `ldid -Sentitlements.plist`.
7. Упаковку в `Payload/Zmeyka.app` и создание финального `Zmeyka.ipa`.
8. Выгрузку готового артефакта `.ipa`.

Для сборки в облаке достаточно запушить репозиторий на GitHub (`git push origin main`) или запустить воркфлоу через вкладку Actions -> `Build Zmeyka iOS 6 ARMv7 IPA` -> `Run workflow`.

## 5. Инструкция по установке на реальный iPhone 4S (iOS 6.1.3) с Windows

### Вариант 1: Устройство с джейлбрейком (Рекомендуемый и самый простой)
На iOS 6.1.3 джейлбрейк делается в один клик (например, через p0sixspwn или Legacy iOS Kit).
1. Установите из Cydia твик **AppSync Unified** (или **AppSync for iOS 6.x**).
2. Подключите iPhone 4S к компьютеру с Windows через 30-pin USB кабель.
3. Откройте утилиту **3uTools** (или iFunBox).
4. Перейдите в раздел **Apps** -> нажмите кнопку **Import & Install ipa**.
5. Выберите файл `Zmeyka.ipa`.
6. Игра установится на рабочий стол iPhone 4S без проверки сертификатов и будет работать неограниченно долго.

### Вариант 2: Установка без джейлбрейка через Sideloadly
1. Скачайте и установите **Sideloadly** для Windows 11 (требуются установленные iTunes и iCloud без магазина Microsoft Store).
2. Подключите iPhone 4S.
3. Перетащите `Zmeyka.ipa` в окно Sideloadly.
4. Введите свой Apple ID.
5. Нажмите кнопку **Start**. Приложение будет автоматически переподписано вашим бесплатным сертификатом разработчика и установлено на устройство.
